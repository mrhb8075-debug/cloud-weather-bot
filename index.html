🌤️ Bulut Tabanlı Kıyafet Önerici

Sunucusuz (Serverless) ve Olay Tabanlı Otomasyon Sistemi

Proje Hakkında

Bu sistem; geleneksel 7/24 çalışan pahalı sunucular yerine bulut bilişimin modern standartları olan **Serverless (Sunucusuz)** ve **Event-Driven (Olay Tabanlı)** mimariyle tasarlanmıştır.

Her sabah otomatik olarak tetiklenen bulut görevleri, anlık hava durumu verilerini analiz eder ve kullanıcıya en uygun giyim kombinini Telegram üzerinden bildirir.

⚙️ Kullanılan Teknolojiler

  • ✅ Bulut Otomasyonu: GitHub Actions (Azure Altyapısı)
  • ✅ Programlama Dili: Python 3.10
  • ✅ Hava Durumu Servisi: OpenWeatherMap API
  • ✅ Bildirim Kanalı: Telegram Bot API
  • ✅ Arayüz Barındırma: GitHub Pages (Static Hosting)
